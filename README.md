# Affan Dumba: Resume Website

Personal resume website styled with HTML5 and CSS3 (Web Development mid-term project).

- `index.html`: page structure
- `style.css`: all styling (CSS variables, flexbox, grid, sticky/fixed positioning, media queries)
- `script.js`: theme toggle, mobile menu, project filter, floating cat

Live site: https://affandumba.github.io/resume-website/
